# DocuMaster

Generates professional documentation for GitHub repositories.

## Features

- Repository connection
- Configuration and generation
- History of results

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/project-gemini-boost.git
cd project-gemini-boost
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
